# Contributing to Unays AI

Start with an issue describing a concrete problem and its expected behavior, or join [Discord](https://discord.gg/fSvV8vqzA) to discuss an idea. Pull requests are welcome.

1. Fork the repository and create a focused branch.
2. Follow the README to start your local workspace.
3. Make your changes without adding credentials, generated databases, or personal user information.
4. Run `npm test` and `npm run check`. For UI work, check desktop, 820px tablet and 390px phone layouts, keyboard navigation and reduced motion.
5. Explain the behavior change, testing, and any limitations in your pull request.

Keep the Unays AI interface free of pricing, payment and upgrade flows. Preserve server-only credentials, isolated previews, accessible controls, clear errors, and guest accounting. Do not display underlying provider identifiers in normal product status messages.

Useful areas for contributions include accessible mobile editing, local-first knowledge tools, optional account adapters, document-processing adapters, translation, and deterministic gateway tests. Coordinate major architecture changes in an issue first.

Contributions are accepted under the repository's MIT license. Be respectful of other contributors and avoid posting private information. Send security vulnerabilities privately through SECURITY.md.
